# 大豆叶片病害检测数据集 | 大豆病害 豆锈病 角斑病 智慧农业 目标检测 YOLO格式 9053期

## 数据集概述

本数据集专注于**大豆叶片常见病害的视觉检测与识别**，服务于智慧农业、病害监测及精准植保。数据涵盖两种典型大豆病害，适配田间巡检、无人机病害普查及植保决策支持等应用。

## 数据三要素解析

**类别与病害覆盖**
*   数据集定义 **2** 类大豆主要病害：
    *   **豆锈病（Bean Rust）**：由真菌引起，在叶片背面产生锈色孢子堆。
    *   **角斑病（ALS - Angular Leaf Spot）**：由细菌引起，叶片形成多角形坏死斑。
*   标注框总数：**豆锈病（17379）**、**角斑病（13820）**，各类别均有充足样本。

![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/33345d92a36646ef8cfb929f58470f90.png)

**数据规模与划分**
*   图像总量 **8800** 张，按 **训练集（6147张）**、**验证集（1786张）**、**测试集（867张）** 完成标准化划分，利于模型开发与独立评估。
*   图像统一尺寸为 **640×640**，可直接输入常见检测网络。

**格式与配套资源**
*   同时提供 **YOLO**、**VOC**、**COCO** 三种通用格式，灵活适配不同目标检测框架。
*   附赠 **YOLOv11n** 完整训练代码（80个epoch）、训练日志及测试代码。
*   提供 **PyQt5 可视化界面**（含全部源码与图标），支持**图片、视频、摄像头实时检测**，并实时显示目标位置、总数、置信度等信息，支持检测结果保存导出，操作直观无需命令行。

## 知识普及：大豆病害视觉检测要点

*   **病害区分特征**：豆锈病呈锈色粉状孢子堆，通常位于叶片背面；角斑病呈多角形坏死斑，边缘清晰。两者形态差异明显，但仍需注意光照与叶片衰老造成的干扰。
*   **田间部署**：该数据集可支撑 **无人机低空巡检** 或 **田间监控系统**，实现大面积病害快速普查。
*   **综合防治**：结合气象数据（如温度、湿度）与病害检测结果，可构建病害发生风险预测模型，指导精准用药。

## 快速开始（代码示例）

YOLO 格式配置文件 `data.yaml` 示例：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
test: ./dataset/images/test
nc: 2
names: ['bean_rust', 'als']
```

加载预训练权重进行训练（YOLOv11n）：
```python
from ultralytics import YOLO
model = YOLO('yolo11n.pt')
model.train(data='data.yaml', epochs=80, imgsz=640, batch=16)
```
